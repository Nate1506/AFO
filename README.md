# Say It Again

A 3-player online co-op radio game about passing a rescue order through a storm.
HQ tells the **rescue van** the safe route. The van radios it to the **aid tent**. The tent relays it to the **village**, where one player leads the villagers to the high hill before the flood clock runs out. Rain, thunder and distance chew up the radio; villagers shout rumours. Players practise repeating, reading back and checking with the source.

Made for the *We R in Trouble Game* contest (game track), All for One University.

## Play

- **Windows build:** run `SayItAgain.exe` (folder `Builds/SayItAgain_Win64`, next to the repository).
- **Solo:** Main menu → PLAY → pick a level → SOLO WITH BOTS. In the lobby, press TAKE on the role you want; bots play the others.
- **Online (3 players):** one player picks a level and presses CREATE ROOM, then reads out the room code. The others type the code and press JOIN. The host presses START.
- **Tutorial:** Main menu → TUTORIAL (solo, village role, about 2 minutes).

### Controls (keyboard + mouse)

| Key | Action |
|---|---|
| WASD / arrows, Shift | Walk, run (van stands still at the tailgate; tent stays inside the tent) |
| Mouse | Look |
| V (hold) | Push-to-talk on the radio |
| Right mouse (hold) | Binoculars (landmark names appear when you hold on one) |
| Tab / Q | Order card and toolbox (quick-chat, Ask HQ) |
| E | Village: call nearby villagers to follow you |
| Esc | Pause (the match keeps running for everyone) |
| H | Skip tutorial tips |

### Levels

1. **Static:** the radio drops words. Fix: say it again, read back.
2. **Rumours:** villagers shout false information and a fake "HQ" message arrives. Fix: check the code word, Ask HQ to confirm.
3-4. Locked (coming soon).

## Develop

- **Unity 6000.3.8f1**, URP 17.3. Open the `AFO` folder in Unity Hub.
- Packages: Netcode for GameObjects 2.13.3, Multiplayer Services 2.4.1 (sessions + Relay), Vivox 16.12.1, Cinemachine 3.1.7, AI Navigation 2.0, Input System 1.18, Multiplayer Play Mode 2.0.2.
- Unity Cloud project: linked (Vivox and Relay enabled on the dashboard). Sign-in is anonymous; each game window uses its own profile.
- If the Package Manager runs out of disk space on C:, the package cache is set to `D:/UnityCache` in `%USERPROFILE%\.upmconfig.toml`.

### Regenerate scenes

All Say It Again scenes, prefabs and level data are generated by code:

`Tools > Say It Again > Build Scenes` (rebuilds `Assets/SayItAgain/Scenes/Lobby.unity` and `Gameplay_Test.unity`, prefabs, data assets and the NavMesh).

### Build

`Tools > Say It Again > Build Windows` → `../Builds/SayItAgain_Win64/SayItAgain.exe`. Only the two Say It Again scenes are included; team prototype scenes are left out.

### Test 3 players on one PC

`Window > Multiplayer > Multiplayer Play Mode`, tick Player 2 and Player 3, press Play, create a room in the main window and join from the others. All windows share one microphone, so this checks routing (who hears whom), not voice quality.

### Code map

| Folder | What |
|---|---|

| `Assets/Resources/Localization/strings.csv` | All on-screen text (English, Thai) |

## Privacy

Voice goes through Vivox live and is never recorded or stored by the game. The settings mic test only shows a level meter.
