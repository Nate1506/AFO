## Description

**Say It Again** is an online co-op radio game for 3 players.

A violent storm is flooding the valley. Three rescuers are far apart and can only talk over a crackling radio:

- **Rescue van:** gets the safe-route order from HQ.
- **Aid tent:** passes the order on.
- **Village:** leads the villagers up to the safe hill before the storm clock runs out.

Distance, rain and thunder cut words out of the radio. Panicking villagers shout false rumours. Repeat the message, read it back, ask "say it again?" and check the code word with HQ, because one wrong word sends the villagers down a flooded road or up collapsing stairs.

At the end, the **Chain Reveal** shows the HQ order next to what each player passed on, and exactly where the message changed.

In real disasters, information passed from person to person gets distorted and rumours fill the gaps. Say It Again lets players practise repeating, reading back and verifying.

### How to play

- Create a room and share the room code with 2 friends, or play **Solo** with bots.
- Each player takes one role: van, tent or village.

| WASD / mouse | Move / look |
| V (hold) | Talk on the radio |
| Tab | Relay card |
| Q | Quick-chat phrases |
| Right mouse | Binoculars |
| E | Call villagers to follow (village) |
| M | Map |
| Esc | Pause |
